# zip-reels

This repo makes the daily Instagram reel for zip. (donebyzip.com).

- Read `PLAYBOOK.md` in full before doing anything. It has the content rules, the spec format and the checks.
- Read `LOG.md` before choosing a topic. Never repeat a topic, angle or hook.
- Talk to the user in Croatian. Everything in the video and the caption is English.
- Never post to Instagram. Never invent statistics, clients, reviews or results.
- MP4s are not committed. Commit only the spec, `LOG.md`, and engine changes.
